# GameZone - Gaming Website

Welcome to **GameZone**, your ultimate destination for exploring and playing the latest games. This project is a simple gaming website built with HTML, CSS, and JavaScript.

## Features

- **Hero Section**: A welcoming section with a call-to-action button to explore games.
- **Featured Games Section**: Displays a list of top games with images, titles, and descriptions.
- **Contact Page**: A form for users to send feedback or inquiries.
- **Responsive Design**: The website is fully responsive and works on all devices.

## Project Structure

## Pages

### 1. **Home Page (`index.html`)**
- Contains a hero section with a call-to-action button.
- Displays featured games with hover effects and click interactivity.

### 2. **Contact Page (`contact.html`)**
- Includes a form for users to submit their name, email, and message.
- Styled with a consistent theme.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling and responsive design.
- **JavaScript**: For interactivity (e.g., hover effects, click events).

## How to Run the Project

1. Clone the repository or download the project files.
2. Open the `index.html` file in your browser to view the website.
3. Navigate to the "Contact" page using the navigation bar.
